# Backend Language Selector - Setup Guide

## Overview
This expert system uses to recommend backend programming languages based on user requirements.

### Create Conda Environment
```bash
conda create -n language_selector python=3.8
conda activate language_selector
```

### Install Dependencies
```bash
pip install -r requirements.txt
```

### Run Application
```bash
python main.py
```
